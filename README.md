# Epic History

Epic History es un proyecto para desarrollar un juego de exploración y experimentar con una mecánica de combate basada en cartas que representan habilidades.

La visión es incorporar muchas clases, cada una con numerosos tipos de habilidades y formas de jugar. El proyecto está abierto a nuevas evoluciones, ideas y conceptos a medida que se desarrollen sus sistemas y su mundo.
